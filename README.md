# قارئ الفصول

موقع ثابت لقراءة الفصول (روايات/نصوص) بدون أي مكتبات أو بناء.

## التشغيل
```
python3 -m http.server 8000
```
ثم افتح http://localhost:8000

## إضافة فصل جديد
1. ضع ملف النص في `chapters/` (مثلاً `4.txt`).
2. أضف سطره في `chapters/index.json`.

## المميزات
- قائمة فصول، التالي/السابق، وأسهم الكيبورد
- حفظ آخر فصل مقروء تلقائيًا
- وضع ليلي وتكبير/تصغير الخط
- يدعم RTL والعربية
